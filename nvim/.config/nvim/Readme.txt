1. Подробный разбор init.lua
Блок 1: Системные пути и основы
Lua

vim.env.PATH = vim.fn.stdpath("data") .. "/mason/bin:" .. vim.env.PATH
vim.g.mapleader = " " 

    PATH: Мы добавляем папку, куда Mason устанавливает языковые серверы (LSP), в системные пути. Это нужно, чтобы Neovim мог запускать pyright и другие инструменты.

    mapleader: Назначаем клавишу-префикс (Пробел). Теперь все команды, начинающиеся с <leader>, будут активироваться через пробел.

Блок 2: Общие настройки (vim.opt)

    number / relativenumber: Включает обычные и относительные номера строк. Относительные удобны для прыжков (например, видишь строку выше на 10 позиций — жмешь 10k).

    clipboard: Связывает буфер обмена Neovim с системным. y в Vim — это Ctrl+C в системе.

    tabstop / shiftwidth: Устанавливает размер отступа в 4 пробела.

    updatetime: Как часто (в мс) Neovim обновляет данные. Важно для быстрой реакции LSP (подсветка ошибок).

Блок 3: Менеджер плагинов Lazy.nvim

Этот блок проверяет, установлен ли lazy.nvim. Если нет — скачивает его из GitHub. Затем загружает список плагинов:

    lspconfig: База для работы с языковыми серверами.

    mason: «Магазин приложений» для LSP, линтеров и форматтеров.

    nvim-cmp: Движок, который рисует выпадающее окно с подсказками.

    catppuccin: Цветовая схема.

Блок 4: Настройка LSP (Новый стандарт)
Lua

if vim.lsp.config then
    vim.lsp.config('pyright', {})
    vim.lsp.enable('pyright')

Это самая важная часть для Neovim 0.11+. Мы не просто запускаем плагин, мы сообщаем самому ядру Neovim: «Если видишь файл .py, запусти сервер pyright». Для Pascal мы явно указываем путь к бинарнику, который мы компилировали вручную.
Блок 5: Автодополнение (CMP)

Здесь настраивается поведение окна подсказок:

    mapping: Назначает клавиши. <CR> (Enter) — подтвердить выбор, <C-Space> — вызвать окно вручную.

    sources: Откуда брать подсказки (LSP, открытый текст в текущем файле или пути к файлам).

2. Подробные кеймапы (Как пользоваться)
Клавиша	Режим	Что делает	Когда применять
F5	Normal	Запуск кода	Когда написал код и хочешь увидеть результат в консоли.
gd	Normal	Go to Definition	Когда хочешь увидеть, где объявлена функция или переменная.
K	Normal	Hover Doc	Показывает описание функции и какие аргументы она принимает.
Ctrl + n	Insert	Next (в CMP)	Листать список подсказок вниз.
Ctrl + p	Insert	Previous (в CMP)	Листать список подсказок вверх.
Enter	Insert	Confirm	Выбрать текущую подсказку.
Leader + r	Normal	Rename	(Можно добавить) Массовое переименование переменной во всем проекте.
3. Рекомендуемые плагины для удобства

Чтобы сделать работу еще комфортнее, рекомендую добавить в блок lazy.setup следующие плагины:

    nvim-neo-tree/neo-tree.nvim: Боковая панель с файлами (как в VS Code). Вызывается обычно по Ctrl + n.

    windwp/nvim-autopairs: Автоматически закрывает скобки и кавычки.

    nvim-lualine/lualine.nvim: Красивая статусная строка внизу (показывает режим, ветку git, язык).

    numToStr/Comment.nvim: Быстрое комментирование строк по gcc.

    akinsho/toggleterm.nvim: Удобный терминал, который можно открывать и скрывать поверх кода.
